# Speaker Notes

Простые спикерские заметки: один HTML-файл, тап слева/справа — листание слайдов,
шестерёнка — редактор. Несколько «колод», импорт/экспорт `.txt`. Всё хранится
локально (`localStorage`), серверной части нет.

## Установка на iPhone (работает без интернета)

1. Разместите папку на любом HTTPS-статик-хостинге (GitHub Pages, Netlify,
   Cloudflare Pages — что угодно). Для GitHub Pages: создайте репозиторий,
   загрузите файлы, Settings → Pages → ветка `master`, папка `/ (root)`.
2. Откройте ссылку в Safari на iPhone.
3. Поделиться → «На экран „Домой“» (Add to Home Screen).
4. Готово: иконка на рабочем столе, приложение запускается в авиарежиме.

После первого открытия service worker закэширует все файлы, интернет больше
не нужен. Заметки живут в памяти приложения; если iOS давно его не использовала,
данные могут быть вычищены — перед важным выступлением делайте Export `.txt`.

## Файлы

- `index.html` — всё приложение
- `sw.js` — service worker (офлайн-кэш)
- `manifest.json` — манифест PWA
- `icon-180.png`, `icon-192.png`, `icon-512.png` — иконки

## Локальный запуск

Любой статический сервер, например:

```
npx http-server .
# или
python -m http.server 8000
```

Примечание: service worker работает только по HTTPS или на `localhost`,
поэтому офлайн-режим проверяйте на хостинге или на `localhost` в десктопном
браузере.

## Заметки по iOS

- Диалоги New / Rename / Delete — собственные (HTML), потому что системные
  `prompt()`/`confirm()` не работают в standalone-режиме (запуск с домашнего
  экрана).
- Память home-screen-приложения отдельная от вкладки Safari: данные,
  введённые в Safari, не видны в установленном приложении, и наоборот.

## Управление во время выступления

- **Экран не гаснет.** В режиме показа слайдов приложение держит экран
  включённым (Wake Lock API, iOS 16.4+). В режиме редактирования — гаснет
  как обычно.
- **Свайпы по всему экрану.** Влево — следующий слайд, вправо — назад,
  в любом месте экрана, не целясь: удобно вслепую одной рукой. Тапы по
  левой/правой половине тоже работают.
- **Кнопка наушников листает слайды** (любой производитель, Bluetooth или
  проводные): одинарное нажатие / двойное — следующий слайд, «предыдущий
  трек» (тройное нажатие или отдельная кнопка — зависит от модели) — назад.
  Работает, пока приложение открыто на включённом экране.
- **Кнопки громкости листать не могут** — Apple не отдаёт их веб-приложениям,
  это ограничение iOS, обойти нельзя.
- **Bluetooth-кликер** (Logitech R500 и т.п.), подключённый к айфону,
  работает из коробки: он шлёт PageDown/стрелки, приложение их понимает.
